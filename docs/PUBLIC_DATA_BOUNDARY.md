# Public data boundary

This repository publishes generalized software and synthetic examples. Private configuration, credentials, internal hosts, client records, exported spreadsheets, original logs, screenshots, production answer traces and source repository history were excluded. Identifying comments and prompts were removed or rewritten. Risk-policy defaults in the public examples are synthetic.

The portfolio starts with a new Git history. Environment examples contain placeholders, and external agent services are disabled by default. Original audit-service adapters do not persist request content in this copy. Local environment files, caches and logs are excluded through `.gitignore`.

Review each project's `PRIVACY.md` and run its scanner before adding new material. Never use workplace data to replace the synthetic examples. Generalization does not assign ownership or grant a license to reused code; this release does not add an open-source license without an established basis for doing so.
