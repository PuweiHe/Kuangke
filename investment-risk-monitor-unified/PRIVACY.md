# Public portfolio data boundary

This copy contains generalized code and synthetic examples. Original environment files, credentials, private hosts, personal names in examples, deployment notes, conversation logs, data exports, spreadsheets, images, and version-control history were not imported. Deployment-specific comments and prompts were removed or rewritten. No anonymization lookup table is included.

Run `python scripts/check_privacy.py` before committing. The scan reports filenames and categories, never matched values. It is a pattern check rather than a proof that all confidential material is absent. Application adapters must enforce authorization before use with real data. Do not replace the synthetic examples with workplace data.
